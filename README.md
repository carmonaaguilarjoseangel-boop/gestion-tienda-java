# Sistema de Gestión de Tienda en Consola

Este es mi primer proyecto en Java. Consiste en un sistema por consola para gestionar un inventario de productos y el registro de usuarios con control de deudas.

## 🚀 Funcionalidades
* **Menú de Usuarios:** Registro, listado, consulta de deudas y gestión de pagos.
* **Menú de Productos:** Registro de inventario, alerta de stock bajo y reabastecimiento.
* **Redimensionamiento:** Manejo de arreglos dinámicos para agregar más datos sin borrar los anteriores.

## 🛠️ Tecnologías utilizadas
* Java (JDK 8)
* Scanner para la entrada de datos por consola

## 📌 Estado del proyecto
Proyecto completado como ejercicio de aprendizaje sobre control de flujo, arreglos y lógica en Java.
